## معرفی

این مخزن شامل نسخه عمومی فعلی کتاب درسی درس **داده‌کاوی** است که برای **نیمسال پاییز ۲۰۲۶**، معادل **سال تحصیلی ۲۰۲۶–۲۰۲۷**، در **دانشگاه آزاد اسلامی، واحد شیراز – دانشکده مهندسی کامپیوتر** تهیه شده است.

این کتاب درسی در دو قالب هماهنگ ارائه شده است:

- **Jupyter Notebook (`.ipynb`)** برای مطالعه تعاملی، نمادگذاری ریاضی، سلول‌های اجرایی Python، مصورسازی‌ها، مثال‌ها و نمایش‌ها.
- **PDF (`.pdf`)** برای مطالعه خطی، مطالعه آفلاین، چاپ، حاشیه‌نویسی و استفاده آرشیوی.

Jupyter Notebookها منبع اصلی و تعاملی کتاب هستند، در حالی که فایل‌های PDF نسخه‌ای پایدار و مناسب مطالعه از فصل‌های متناظر ارائه می‌کنند.

این پروژه صرفاً مجموعه‌ای فشرده از تعریف‌ها نیست. ساختار آن در سراسر فصل‌های منتشرشده، توضیحات مفهومی، شهود، صورت‌بندی‌های ریاضی، مثال‌ها، نمودارها، مصورسازی‌ها، نمونه‌های پیاده‌سازی و زمینه‌های کاربردی را در کنار یکدیگر قرار می‌دهد.

## نسخه ۲ کتاب درسی

این مخزن **نسخه دوم** یک پروژه پیشین برای کتاب درسی درس داده‌کاوی است.

اگرچه این انتشار به‌طور رسمی **نسخه ۲** است، نباید آن را یک بازبینی جزئی یا ادامه ساده جزوه‌های قبلی در نظر گرفت.

نسخه دوم به‌طور **اساسی بازطراحی، بازنویسی، بازسازمان‌دهی، گسترش و بازپردازش** شده است.

بخش‌های قابل‌توجهی از مطالب از پایه بازنگری شده‌اند؛ از جمله ساختار توضیحات، نحوه ارائه مفاهیم، پرداخت ریاضی، مثال‌ها، عناصر بصری، سازمان‌دهی Jupyter Notebookها و نمونه‌های عملی.

در نتیجه، نسخه ۲ باید به‌عنوان یک **ویرایش جدید و به‌طور اساسی بازپردازش‌شده** از کتاب درسی در نظر گرفته شود، نه صرفاً نسخه‌ای ویرایش‌شده از نسخه ۱.

بنابراین، رابطه میان این دو نسخه را می‌توان به شکل زیر خلاصه کرد:

```text
نسخه ۱
   │
   │  بازسازمان‌دهی، بازنویسی،
   │  گسترش، بازطراحی و بازپردازش اساسی
   ▼
نسخه ۲
```

نسخه ۱ پیشینه مفهومی این پروژه است، اما کتاب درسی منتشرشده در اینجا نمایانگر نسخه ۲ فعلی است.

<https://github.com/Amir-Mohammd-Asadjoo/Data-Mining-Textbook>

## Clone

```bash
git clone https://github.com/Amir-Mohammd-Asadjoo/Data-Mining-Textbook.git
```

## ورود به مخزن

```bash
cd Data-Mining-Textbook
```

## Start Jupyter

```bash
jupyter lab
```

یا:

```bash

```

<a name="toc-git-hygiene"></a>
# اصول پیشنهادی Git

این مخزن برای نگهداری محتوای آموزشی درس و دارایی‌های مرتبط در نظر گرفته شده است، نه فراداده‌های توسعه محلی.

از commit کردن موارد زیر خودداری کنید:

```text
.git/
.ipynb_checkpoints/
__pycache__/
*.py[cod]
```

مخزن فعلی با استفاده از `.gitignore` پوشه‌های checkpoint مربوط به Jupyter را خارج از کنترل نسخه نگه می‌دارد.

<a name="toc-release-policy"></a>
# رویکرد انتشار

هدف مخزن عمومی، حفظ و توزیع محتوای آموزشی فعلی نسخه ۲ به شکلی پایدار، خوانا و شفاف است.

سیاست انتشار عمداً ساده در نظر گرفته شده است:

- فصل‌های تکمیل‌شده منتشر می‌شوند.
- فصل‌های در حال توسعه تا زمان آماده‌شدن برای انتشار، خصوصی باقی می‌مانند.
- نسخه‌های Jupyter Notebook و PDF هم‌زمان منتشر می‌شوند.
- انتساب نویسندگان به‌صورت صریح درج می‌شود.
- محتوای شخص ثالث همچنان تابع حقوق مربوط به خود است.
- نسخه‌های آینده ممکن است هم محتوا و هم سازمان‌دهی مخزن را بازنگری کنند.

<a name="toc-quality"></a>
# کیفیت و دقت

Jupyter Notebookها و فایل‌های PDF، محتوای آموزشی درس هستند.

در فرایند تهیه مطالب دقت لازم به کار گرفته شده است، اما محتوای آموزشی همچنان ممکن است شامل موارد زیر باشد:

- خطاهای تایپی
- مشکلات قالب‌بندی
- خطاهای ریاضی
- مشکلات پیاده‌سازی
- پیوندهای خراب
- توضیحات ناقص

از خوانندگان دعوت می‌شود مشکلات را از طریق GitHub Issues گزارش کنند.

هنگام گزارش یک مشکل فنی، موارد زیر را درج کنید:

- شماره فصل
- مسیر فایل
- بخش
- شرح مشکل
- پیام خطا، در صورت وجود
- نسخه Python
- نسخه بسته‌های مرتبط

این اطلاعات بازتولید و رفع مشکل را آسان‌تر می‌کند.

<a name="toc-contributing"></a>
# مشارکت و گزارش خطا

این مخزن در درجه اول یک منبع آموزشی منتشرشده است، نه یک پروژه نرم‌افزاری عمومی.

با این حال، بازخوردهای فنی و ویرایشی مورد استقبال هستند.

## Appropriate Issue Types

موارد زیر نمونه‌هایی از این دسته هستند:

- خطاهای تایپی
- پیوندهای داخلی خراب
- تصاویر مفقود
- مسیرهای نادرست تصاویر
- مشکلات نمایش Jupyter Notebook
- مشکلات اجرای کد
- ناهماهنگی‌های قالب‌بندی
- ارجاعات نادرست به فصل‌ها
- مشکلات ارجاع
- مشکلات انتساب
- مشکلات مستندات

## Suggested Issue Template

```text
فصل:
فایل:
Section:
مشکل:
مورد انتظار:
مشاهده‌شده:
اصلاح پیشنهادی:
محیط:
```

نگه‌دارندگان مخزن ممکن است از GitHub Issues برای پیگیری اصلاحات و بازبینی‌های آینده استفاده کنند.
